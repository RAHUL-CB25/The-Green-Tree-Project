# Green Tree Initiative

A responsive website built for the Green Tree Initiative project.

The project contains a home page and a donation page based on the provided wireframes.

## Live Demo

[View Live Website](DEPLOYMENT_LINK)

## Technologies Used

* HTML
* CSS

## Project Pages

* Home Page
* Donation Page

## How to Clone the Project

Clone the repository using:

```bash
git clone :
```

Go to the project folder:

```bash
cd Green-Tree-Initiative
```

Open the project in VS Code:

```bash
code .
```

## How to Run the Project

This project uses only HTML and CSS, so no additional installation is required.

Open `html/index.html` in a browser to view the Home Page.

Open `html/donation.html` in a browser to view the Donation Page.
